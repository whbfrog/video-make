# 奶爸日记 · 用原视频配音重新生成画面

一段完全由代码绘制的原创卡通短片：**爸爸带着两个娃，每天鸡飞狗跳**。
画面全部重新生成，声音用原视频的音轨（配音 + 配乐）。

| # | 场景 | 内容 |
|---|------|------|
| 0 | 片头 | 《奶爸日记》：一个爸爸 × 两个娃 = 每天鸡飞狗跳 |
| 1 | 清晨 | 六点半，两个娃溜进卧室在床上蹦，闹钟狂响，爸爸被吵醒 |
| 2 | 早餐 | 爸爸系着围裙煎蛋，妹妹打翻牛奶洒一地 |
| 3 | 居家办公 | 爸爸戴耳机开会，身后两娃枕头大战，领导问“怎么这么吵” |
| 4 | 辅导作业 | 哥哥“不想写”，一道题讲八遍，妹妹在墙上涂鸦，爸爸气得**七窍生烟** |
| 5 | 抢玩具 | 两娃抢机器人、哭闹告状，爸爸抱头崩溃 |
| 6 | 深夜 | 娃睡了，满地狼藉，爸爸独自在阳台叹气：日子还得继续 |
| 7 | 温暖 | 孩子送上画“爸爸辛苦了”，拥抱，满屏爱心 |
| 8 | 片尾 | 夕阳下三人牵手：孩子带来的快乐，永远比烦恼更多 |

## 角色设计（全片统一）

- **爸爸**：黑框眼镜、侧分短发、蓝衬衫深色裤；表情有说话、疲惫、震惊、生气（脸变红、露牙、青筋、头顶和两耳冒烟）、开心
- **哥哥**：刺猬头、红色 T 恤（胸前黄星星）、蓝裤子白球鞋
- **妹妹**：双马尾粉色蝴蝶结、黄色连衣裙、粉鞋子、腮红

角色参数都在 `make_video.py` 的 `CHAR` 表和 `head()` / `face()` 函数里，改颜色、发型只需要改这几处。

## 特效

- **每句歌词/字幕都有特效**：弹跳、打字机、波浪、弹出、滑入、彩虹、盖章，7 种轮流；
  每句开头还会从文字处炸开一圈星星 / 爱心 / 音符 / 彩纸。
- **场景之间有转场**：圆形放大、横向推移、爱心展开、斜切、星星铺满、缩放淡出、百叶窗。

## 使用方法

需要 Python 3.9+。

```bash
pip install pillow numpy imageio-ffmpeg yt-dlp

# 1. 只下载原视频的声音（不要画面）；如果视频有字幕会顺带转成 LRC
./fetch_audio.sh "https://www.youtube.com/watch?v=8j-hR4fJywU"

# 2. 生成视频：画面总长自动等于音频长度，各场景按比例拉伸
python3 make_video.py --audio audio/original.m4a --out output/naiba.mp4

# 3. 让每句歌词带特效出现（歌词时间要和音频对上）
python3 make_video.py --audio audio/original.m4a --lyrics lyrics/lyrics.lrc --out output/naiba.mp4
```

常用参数：

| 参数 | 作用 |
|------|------|
| `--lyrics 文件` | 歌词文件，支持 `.lrc` / `.srt` / `.vtt` / `.txt`（纯文本按行平均分配时间） |
| `--lyrics-offset 秒` | 歌词整体提前/延后，例如 `-0.5` |
| `--no-subs` | 不显示任何字幕和歌词（气泡对白仍保留） |
| `--duration 90` | 不给音频时的预览时长 |
| `--stills 目录` | 每个场景导出几张截图，快速检查画面 |
| `--font 字体路径` | 找不到中文字体时手动指定（Windows 可用 `C:/Windows/Fonts/msyh.ttc`） |

没有 `--lyrics` 时，底部显示的是故事旁白字幕（同样带逐句特效）。

歌词格式见 `lyrics/example.lrc`：句首可写 `{stamp}`、`{rainbow}` 等指定某句的特效。
