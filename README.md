# 奶爸日记 · 水彩动画 MV

爸爸带着两个娃，每天鸡飞狗跳：早起被吵醒、早餐打翻牛奶、开会时娃在背后打仗、抢玩具、辅导作业气到七窍生烟、深夜一个人收拾……
可孩子一张画、一句“爸爸辛苦了”，所有烦恼都化了——**孩子带来的快乐，永远多于烦恼。**

画面全部用代码画出来（原创角色：爸爸、哥哥、妹妹），声音用歌曲原音轨，所有动作都卡在 88 BPM 的节拍上。

## 做法（参考 [JohnHeibel/PDoomVideo](https://github.com/JohnHeibel/PDoomVideo) 的思路重新实现）

- **p5.js + p5.brush**：水彩平涂 + 粗细变化的墨线，线条每秒“沸腾”12 次，像手绘动画；纸纹和暗角叠在最上层。
- **每个镜头都是时间 t 的纯函数**：帧可以并行、乱序渲染；镜头 1.5–4 秒，一个镜头一个完整的笑点。
- **节拍工具**：`B(n)` 第 n 拍的时间、`pulse` 拍点冲击、`hopB` 拍点落地的跳跃、`swingB` 拍点到极值的摆动；重要动作都放在拍点上。
- **镜头系统**：`camBegin(cx, cy, zoom, rot)` 推、拉、摇、斜角、震屏。
- **角色系统**（`src/family.js`）：表情库 + `mood()`（换表情前先眯眼压扁再弹开）+ `move()` 节拍舞步（bounce/hop/roof/sway/spin/stomp/shimmy/clap…）。
- **手写中文**：站酷快乐体；漫画拟声字 `sfx()` 弹出、抖动、淡出。
- **章节之间**用笔刷横扫转场；副歌 1~3 角落里的“耐心值”温度计每拍掉一截，副歌 4 变成“幸福值”一路涨到爆表。

## 渲染

需要 Node.js 18+、Chromium/Chrome、ffmpeg（或 `pip install imageio-ffmpeg`）。音频路径写在 `songs/pdoom.json`。

```bash
npm install
node render.mjs --sheet=10,24,60 --cols=3 --out=out/check.jpg   # 接触表，快速看画面
node render.mjs --clip=22:40 --out=out/clip.mp4                   # 带音频的片段
node render.mjs --frames=0:157 --workers=4                         # 全片逐帧 → out/frames（可断点续渲）
node render.mjs --encode --out=out/naiba.mp4                       # 帧 + 原曲 → MP4
```

- **有显卡的机器加 `--gpu`**：速度快很多，并换回 p5.brush 真正的水彩晕染。例：`node render.mjs --frames=0:157 --workers=4 --gpu`
- 会自动在常见位置找 Chrome（Windows / Mac / Linux），找不到时用 `--chrome=<路径>` 或环境变量 `CHROME`。
- 音频不在仓库里：从 [PDoomVideo](https://github.com/JohnHeibel/PDoomVideo) 的 `assets/pdoom.mp3` 复制到 `audio/original.mp3`（路径见 `songs/pdoom.json`）。
- 没有显卡时用 SwiftShader 软件渲染；p5.brush 的真水彩晕染在软件渲染下太慢（每块 2 秒多），默认用“多层抖动平涂”模拟；有显卡时在页面地址加 `?realfill` 可换回真晕染。
- 在浏览器里打开 `studio.html` 可以拖动进度条逐帧预览。

## 歌词

歌词不随项目提供。把歌词写进 LRC 文件（`lyrics/pdoom_timing.lrc` 是这首歌的时间模板，把“（第N句）”换成歌词），渲染时加 `--lyrics=lyrics/你的文件.lrc`，底部会出现逐字点亮的歌词条。
